# ddeploy

Free up space on your Mac. [ddeploy](https://ddeploy.com) lists what is using your storage, line by line, in plain English, including the "System Data" Apple won't explain, and deletes the safe stuff with one click. Everything runs on your Mac: no account, no uploads, works offline.

- Website and download: **https://ddeploy.com** (macOS 14+, Apple Silicon and Intel, notarized by Apple)
- Homebrew: `brew trust anandat/ddeploy && brew install --cask anandat/ddeploy/ddeploy`
- Free to scan. Cleaning is ddeploy Pro, $9.99 once, one Mac, no subscription.

This repository holds the website, the Sparkle appcast and the release downloads.
Reviews are GitHub issues labelled `review` (use the issue template). Questions go in Discussions.
